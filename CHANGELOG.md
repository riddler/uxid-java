# Changelog

## Unreleased

The Java port of uxid: prefixed, K-sortable identifiers a person can read,
wire-compatible with the Elixir `uxid` package. No version has been released
yet. The build is in place: the Maven coordinate `systems.riddler:uxid`, the
module and package `systems.riddler.uxid`, a Java 17 floor and the build gate.
The generation, decoding and validity checks arrive in later changes.
